# AGENTS.md

H3VAL Music marketing site. TanStack Start (React 18, file-based routing) on
Vite, deployed to Cloudflare Workers via `@cloudflare/vite-plugin`. Styling
is Tailwind CSS v4 + shadcn/ui-style primitives (Radix + CVA).

## Stack

- **Framework**: `@tanstack/react-start` + `@tanstack/react-router` (routes in `app/routes/`, generated tree in `app/routeTree.gen.ts` — never edit by hand)
- **Build/dev**: Vite 7
- **Deploy target**: Cloudflare Workers (`wrangler.jsonc`)
- **Styling**: Tailwind v4 (`app/tailwind.css`), `cn()` helper in `app/lib/utils.ts`
- **UI primitives**: `app/components/ui/*` (button, card, input, label — Radix + `class-variance-authority`)
- **Lint/format**: Biome (`biome.json`) — single source of truth, no ESLint/Prettier
- **Types**: TypeScript strict mode, `noEmit` (Vite builds), path alias `~/*` → `app/*`
- **E2E**: Playwright, tests in `e2e/`, runs against `npm run preview` on port 8788
- **Git hooks**: lefthook runs `biome check --write` on staged files pre-commit

## Commands

```sh
npm run dev         # vite dev server
npm run build        # production build
npm run lint          # biome check
npm run format        # biome check --write
npm run typecheck    # tsc (no emit)
npm run e2e           # playwright tests (builds + wrangler preview first)
npm run deploy        # build + wrangler deploy
```

Always run `npm run lint` and `npm run typecheck` after changes. Run
`npm run e2e` when routes/page content change.

## Conventions

- Routes live in `app/routes/*.tsx`, one file per page; `__root.tsx` sets
  `<head>` meta/title per TanStack Start conventions.
- Reuse existing `app/components/ui/*` primitives before adding new ones or
  a new dependency (Radix is already installed).
- Biome enforces double quotes, organized imports, a11y rules — don't
  hand-format, just run `npm run format`.
- Node >= 24 required (see `.nvmrc`).

## Don't

- Don't hand-edit `app/routeTree.gen.ts` — it's generated by the TanStack
  router plugin on build/dev.
- Don't add ESLint/Prettier config — Biome already covers both.
- Don't add new UI/icon/CSS libraries when Radix, lucide-react, or Tailwind
  already solve it.
